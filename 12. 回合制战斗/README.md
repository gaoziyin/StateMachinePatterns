## 概述

经典JRPG风格的回合制战斗系统，实现了**行动队列**、**技能系统**、**元素克制**、**状态效果**等核心机制。类似《最终幻想》、《勇者斗恶龙》的战斗体验。

## 核心系统

| 系统 | 描述 |
|------|------|
| **行动队列** | 基于速度的回合顺序 |
| **技能系统** | 技能威力、消耗、冷却 |
| **元素系统** | 7种元素相互克制 |
| **状态效果** | Buff/Debuff，持续效果 |
| **伤害计算** | 攻防比、暴击、元素加成 |

## 战斗流程图

### 战斗阶段

```mermaid
stateDiagram-v2
    [*] --> BattleStart: 战斗开始
    
    BattleStart --> TurnStart: 初始化完成
    
    TurnStart --> ActionSelect: 取出行动单位
    TurnStart --> TurnEnd: 队列为空
    
    ActionSelect --> ActionExecute: 选择技能和目标
    ActionSelect --> TurnStart: 单位无法行动
    
    ActionExecute --> Victory: 敌方全灭
    ActionExecute --> Defeat: 我方全灭
    ActionExecute --> TurnStart: 继续行动
    ActionExecute --> TurnEnd: 回合结束
    
    TurnEnd --> TurnStart: 新回合
    TurnEnd --> Victory: 敌方全灭
    TurnEnd --> Defeat: 我方全灭
    
    Victory --> [*]
    Defeat --> [*]
```

## 技能系统

### 技能列表

| 技能 | 消耗 | 冷却 | 威力 | 目标 | 效果 |
|------|------|------|------|------|------|
| 普通攻击 | 0 | 0 | 1.0x | 单体 | - |
| 火球术 | 15 | 0 | 1.5x | 单体 | 30%燃烧 |
| 暴风雪 | 30 | 2 | 0.8x | 群体 | 20%冰冻,50%减速 |
| 雷击 | 20 | 1 | 1.8x | 单体 | 25%麻痹 |
| 治愈术 | 20 | 0 | 30%HP | 单体 | 治疗 |
| 群体治愈 | 40 | 2 | 20%HP | 群体 | 治疗 |
| 毒刃 | 10 | 0 | 1.2x | 单体 | 50%中毒 |
| 狂暴 | 20 | 4 | - | 自身 | +80%攻,-30%防 |
| 盾击 | 15 | 2 | 0.8x | 单体 | 40%眩晕 |
| 反击姿态 | 10 | 2 | - | 自身 | 反击2回合 |

### 伤害公式

```
基础伤害 = 攻击力 × 技能威力

防御减伤 = 防御力 / (防御力 + 100)
减伤后伤害 = 基础伤害 × (1 - 防御减伤)

暴击判定 (10%): 伤害 × 1.5
元素克制: 伤害 × 1.5
元素抵抗: 伤害 × 0.75

最终伤害 = 取整(以上计算) × 随机浮动(±10%)
```

## 状态效果

### Buff (增益)

| 效果 | 图标 | 描述 |
|------|------|------|
| 攻击提升 | ⚔️↑ | 增加攻击力 |
| 防御提升 | 🛡️↑ | 增加防御力 |
| 速度提升 | 💨↑ | 增加速度 |
| 再生 | 💚 | 每回合恢复HP |
| 护盾 | 🔰 | 吸收伤害 |
| 反击 | ↩️ | 受到攻击时反击 |

### Debuff (减益)

| 效果 | 图标 | 描述 |
|------|------|------|
| 攻击下降 | ⚔️↓ | 降低攻击力 |
| 防御下降 | 🛡️↓ | 降低防御力 |
| 速度下降 | 💨↓ | 降低速度 |
| 中毒 | ☠️ | 每回合损失HP |
| 燃烧 | 🔥 | 每回合损失HP |
| 冰冻 | ❄️ | 无法行动 |
| 麻痹 | ⚡ | 无法行动 |
| 沉默 | 🔇 | 无法使用技能 |
| 睡眠 | 💤 | 无法行动 |
| 眩晕 | 💫 | 无法行动 |

3. **装备系统**: 武器、防具影响属性
4. **召唤技能**: 召唤物作为额外单位
5. **连携技**: 多角色联合攻击
6. **属性成长**: 经验值和升级系统
